# Parchi

Little notes, to-do lists and photos that stay on your Mac desktop. No limits, no account, no subscription. Everything stays on your Mac.

## Download

**[Download Parchi.dmg](https://github.com/himanshu-45naik/parchi/releases/latest/download/Parchi.dmg)**

Needs macOS 14 or later on Apple Silicon.

Open the DMG and drag Parchi to Applications. The app isn't notarized by Apple, so macOS blocks the first launch. Try to open it once, then go to System Settings > Privacy & Security and click **Open Anyway**.

## Use

- `⌃⌥N` new note, `⌃⌥T` new to-do list, `⌃⌥M` main window
- Drag a card to move it, drag its edges to resize, click it to edit
- Pick a theme or photo look from a card's `...` menu

## Build from source

Needs the Xcode Command Line Tools.

```bash
scripts/build-app.sh
```
